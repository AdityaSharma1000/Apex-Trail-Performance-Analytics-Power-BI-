# Apex Trail Performance Analytics Dashboard

## 📊 Project Overview
This repository contains a comprehensive Power BI project designed for **Apex Trail** an imaginable company. The goal of this project was to transform raw business data into actionable insights, providing a centralized view of performance metrics, sales trends, and operational efficiency.

## 🛠️ Tech Stack & Tools
*   **Power BI Desktop**: Dashboarding and Data Visualization.
*   **Power Query**: Data cleaning, transformation, and ETL processes.
*   **DAX (Data Analysis Expressions)**: Created custom measures and calculated columns for advanced KPIs.
*   **Excel**: Primary data source.

## 🧠 Data Modeling & Transformation
*   **ETL Process**: Performed data cleaning in Power Query, including removing duplicates, handling missing values, and formatting data types.
*   **Star Schema**: Established a robust data model by creating relationships between fact tables and dimension tables to optimize report performance.
*   **DAX Measures**: Developed key metrics such as Total Revenue, Year-over-Year (YoY) Growth, and Moving Averages.

## 📈 Key Insights & Features
*   **Interactive Visuals**: Includes slicers for date ranges, regions, and product categories for granular analysis.
*   **Trend Analysis**: Visualized month-over-month growth to identify seasonal peaks.
*   **KPI Tracking**: High-level summaries of critical business health indicators.
*   **User-Centric Design**: Focused on a "clean and suave" aesthetic (Moody/Corporate theme) to ensure readability for stakeholders.

## 📂 Project Structure
*   `Apex_Trail_Dashboard.pbix`: The main Power BI project file.
*   `/Data`: Contains the raw Excel datasets used for the analysis.
*   `/Screenshots`: Images of the dashboard for quick viewing.

## 🚀 How to Use
1. Clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. (Optional) Refresh the data source if you update the files in the `/Data` folder.
